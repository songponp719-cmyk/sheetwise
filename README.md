# Sheetwise — Excel comparison

เว็บแอปสำหรับจัดระเบียบและเปรียบเทียบไฟล์ Excel/CSV โดยประมวลผลในเบราว์เซอร์ ไฟล์ต้นฉบับไม่ถูกส่งไปยังเซิร์ฟเวอร์

## สิ่งที่ทำได้

- เปิดไฟล์ `.xlsx`, `.xls` และ `.csv` ขนาดไม่เกิน 25 MB ต่อไฟล์; Excel รองรับหลายชีตในไฟล์เดียว
- ใช้แท็บ **สร้างตาราง** เพื่ออัปโหลดไฟล์ Excel แยกจากหน้าการเปรียบเทียบ พรีวิว/ค้นหา/กรองชีต เลือกหลายแถวแล้วเพิ่มลงชีตปลายทางที่เลือกได้ และเพิ่มแถวต้นทางซ้ำได้ พร้อมข้อความยืนยันกลางหน้าจอหลังเพิ่มข้อมูล ตารางใหม่เพิ่มชีตและตั้งหรือเปลี่ยนชื่อชีตได้ โดยการส่งออกจะสร้าง workbook ที่แยกข้อมูลตามชีตและคงชื่อชีตไว้
- แสดงตัวอย่างข้อมูล ค้นหาในแต่ละไฟล์ และเลือกคอลัมน์ Key แยกกันได้
- ดูตารางพรีวิวของแต่ละไฟล์ได้ทันทีหลังอัปโหลด โดยแสดงไฟล์ 1 และไฟล์ 2 วางข้างกัน พร้อมแบ่งหน้าเพื่อไล่ดูข้อมูล
- จัดระเบียบข้อมูลเบื้องต้น: ลบแถวว่าง ตัดช่องว่างหัว/ท้าย สร้างชื่อให้หัวตารางที่ว่าง และลบแถวข้อมูลว่าง
- แสดงผลเปรียบเทียบในตารางเดียว โดยรวมคอลัมน์ที่ชื่อเหมือนกันไว้ด้วยกัน และเรียงข้อมูลตาม Key; คู่ที่จับกันได้จะแสดงเป็นสองแถวต่อกัน (ไฟล์ 1 แล้วไฟล์ 2) พร้อมคอลัมน์แหล่งข้อมูล โดยไม่แสดงป้ายสถานะว่าตรงกัน
- เปรียบเทียบทุกชีตที่มีข้อมูลและชื่อเหมือนกันในทั้งสองไฟล์โดยอัตโนมัติ พร้อมเลือก Key แยกในแต่ละคู่ชีต; ชีตที่ไม่มีชื่อคู่กันจะแสดงเป็นข้อมูลเฉพาะของไฟล์นั้น
- ตรวจหาแถวหัวตารางจาก 20 แถวแรกของแต่ละชีต เพื่อช่วยข้ามแถวชื่อรายงาน/ข้อมูลเกริ่นนำก่อนหัวคอลัมน์ และใช้ชื่อหัวตารางที่ตรวจพบในตัวเลือก Key
- กรองตารางผลลัพธ์ตามชื่อชีต และค้นหาข้อความแบบตรงกันหรือใกล้เคียง (แก้คำผิดเล็กน้อยได้)
- พรีวิวไฟล์ 1 และไฟล์ 2 วางข้างกัน พร้อมค้นหาและแบ่งหน้าแยกกัน
- เลือกแถวแยกจากการส่งออกได้: เปิดโหมดเลือกแล้วนำแถวที่เลือกออกจากตาราง หรือใช้ปุ่ม `×` เพื่อนำออกทันทีทีละแถว
- มีหน้าต่างยืนยันก่อนนำแถวออกจากตาราง และปุ่ม `×` อยู่หน้าข้อมูลของแต่ละแถว
- ส่งออกตารางผลลัพธ์ที่เหลืออยู่และตรงกับตัวกรองชีต/คำค้นหาเป็น Excel ได้ โดยไม่แก้ไขไฟล์ต้นฉบับ
- ใช้สเกลตัวอักษรเว็บมาตรฐาน โดยมีข้อความเนื้อหาหลักขนาด 16px และข้อความรอง/คำอธิบายขนาด 14px
- จับคู่ Key โดยไม่สนตัวพิมพ์เล็ก/ใหญ่; Key ว่างจะไม่ถูกนำมาเทียบ และกรณี Key ซ้ำจะจับคู่ตามลำดับแถว

> การจัดรูปแบบวันที่และตัวเลขคงค่าตามที่ไลบรารีอ่านได้ เพื่อหลีกเลี่ยงการเปลี่ยนความหมายของข้อมูล เช่น รหัสที่มีเลขศูนย์นำหน้า

## ติดตั้งและรัน

ต้องใช้ Node.js 18 ขึ้นไป และ npm

1. เปิด Terminal ในโฟลเดอร์โปรเจกต์
2. ติดตั้ง dependencies:

   ```bash
   npm install
   ```

3. เริ่มเซิร์ฟเวอร์สำหรับพัฒนา:

   ```bash
   npm run dev
   ```

4. เปิด URL ที่ Vite แสดงใน Terminal (โดยปกติคือ `http://localhost:5173`)

สร้างไฟล์สำหรับเผยแพร่ด้วย `npm run build`; ทดสอบ build ในเครื่องด้วย `npm run preview`

## เผยแพร่บน GitHub Pages

โปรเจกต์มี GitHub Actions สำหรับ build และ deploy อัตโนมัติเมื่อ push ไปยัง branch `main`

1. สร้าง GitHub repository และ push โค้ดชุดนี้ขึ้น branch `main`
2. ใน repository เปิด **Settings → Pages** แล้วตั้ง **Build and deployment → Source** เป็น **GitHub Actions**
3. รอ workflow **Deploy Sheetwise to GitHub Pages** ทำงานสำเร็จ จากนั้นเปิด URL ที่แสดงใน **Settings → Pages** หรือใน deployment environment `github-pages`

Vite จะตั้ง base path ตามชื่อ repository ให้โดยอัตโนมัติ; การ build และพัฒนาในเครื่องยังใช้ root path ตามปกติ

## หมายเหตุข้อมูลส่วนบุคคล

การอ่าน เปรียบเทียบ และส่งออกเกิดขึ้นในแท็บเบราว์เซอร์โดยใช้ SheetJS ไม่มี backend และไม่ส่งเนื้อหาไฟล์ผ่านเครือข่ายโดยแอปนี้ อย่างไรก็ตาม ไฟล์ที่มีข้อมูลอ่อนไหวควรใช้บนอุปกรณ์ที่เชื่อถือได้ และสามารถใช้งานแบบออฟไลน์ได้หลังติดตั้ง dependencies และ build แล้ว
